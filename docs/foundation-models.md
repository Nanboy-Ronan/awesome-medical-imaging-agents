# Backbone Foundation Models

Pretrained medical LLMs, multimodal LLMs, and image encoders frequently wrapped by the agent systems above; included for reference, not as agents themselves.

- [MedSAM3: Delving into Segment Anything with Medical Concepts](https://arxiv.org/abs/2511.19046) - Adapts SAM3 to medical concepts for text-prompted medical image and video segmentation; listed as a foundation model, not a standalone agent (arXiv, 2025; [Code](https://github.com/Joey-S-Liu/MedSAM3)).
- [BioGPT: Generative Pre-trained Transformer for Biomedical Text Generation and Mining](https://arxiv.org/abs/2210.10341) - Biomedical text generation backbone often used inside downstream agent pipelines (arXiv, 2023).
- [BiomedCLIP: a multimodal biomedical foundation model pretrained from fifteen million scientific image-text pairs](https://arxiv.org/abs/2303.00915) - Contrastive image-text encoder trained on PMC-15M; the default retrieval and zero-shot classification backbone inside many biomedical agent toolchains (arXiv, 2023).
- [BioMedGPT: Open Multimodal Generative Pre-trained Transformer for BioMedicine](https://arxiv.org/abs/2308.09442) - Vision-language foundation model for biomedical image/text understanding; typically wrapped by agent controllers (arXiv, 2023).
- [ChatCAD+: Towards a Universal and Reliable Interactive CAD using LLMs](https://arxiv.org/abs/2305.15964) - Interactive CAD/VQA backbone for medical imaging workflows, not an agent by itself (arXiv, 2023).
- [ChatDoctor: A Medical Chat Model Fine-Tuned on a Large Language Model Meta-AI (LLaMA) Using Medical Domain Knowledge](https://arxiv.org/abs/2303.14070) - Clinical dialogue-tuned base model commonly embedded inside agent toolchains (arXiv, 2023).
- [CheXagent: A Vision-Language Foundation Model to Enhance Efficiency of Chest X-ray Interpretation](https://arxiv.org/abs/2401.12208) - Instruction-tuned chest X-ray foundation model with the CheXbench evaluation suite; widely used as the imaging expert wrapped by radiology agents (arXiv, 2024; [Code](https://github.com/Stanford-AIMI/CheXagent)).
- [ClinFusion: A Vision-Centric Multimodal LLM System for Holistic Medical Understanding](https://arxiv.org/abs/2607.24743) - Vision-centric multimodal LLM with a cascaded 2D/3D medical image encoder and a region-of-interest-grounded evaluation framework (MedIF-Bench); state-of-the-art open medical MLLM that downstream systems can augment with agentic tool use (arXiv, 2026).
- [CONCH: A visual-language foundation model for computational pathology](https://www.nature.com/articles/s41591-024-02856-4) - Histopathology vision-language model trained on 1.17M image-caption pairs; provides the text-alignable tile representations that pathology agents query (Nature Medicine, 2024; [Code](https://github.com/mahmoodlab/CONCH)).
- [CT-CLIP: Generalist Foundation Models from a Multimodal Dataset for 3D Computed Tomography](https://arxiv.org/abs/2403.17834) - Chest CT vision-language model and CT-CHAT conversational assistant released with the CT-RATE dataset; a common 3D volumetric backbone for CT agents (arXiv, 2024; [Code](https://github.com/ibrahimethemhamamci/CT-CLIP)).
- [DoctorGLM: Fine-tuning your Chinese Doctor is not a Herculean Task](https://arxiv.org/abs/2304.01097) - Chinese clinical assistant model leveraged as the core reasoning engine in many agent systems (arXiv, 2023).
- [HealthGPT: A Medical Large Vision-Language Model for Unifying Comprehension and Generation via Heterogeneous Knowledge Adaptation](https://arxiv.org/abs/2502.09838) - Unifies medical visual comprehension and image generation in one autoregressive model, giving agent controllers a single backbone for both reading and synthesizing images (arXiv, 2025; [Code](https://github.com/DCDmllm/HealthGPT)).
- [HuatuoGPT-Vision, Towards Injecting Medical Visual Knowledge into Multimodal LLMs at Scale](https://arxiv.org/abs/2406.19280) - Scales medical visual instruction tuning with the 1.3M-sample PubMedVision corpus; a widely adopted open multimodal backbone for Chinese and English medical agents (arXiv, 2024; [Code](https://github.com/FreedomIntelligence/HuatuoGPT-Vision)).
- [HuatuoGPT: Towards Taming Language Model to Be a Doctor](https://arxiv.org/abs/2305.15075) - Chinese clinical dialogue and diagnosis base model used in downstream agent systems (arXiv, 2023).
- [Lingshu: A Generalist Foundation Model for Unified Multimodal Medical Understanding and Reasoning](https://arxiv.org/abs/2506.07044) - Generalist medical MLLM with a multi-stage training recipe and the MedEvalKit evaluation harness; a strong open reasoning backbone for downstream agents (arXiv, 2025; [Code](https://github.com/alibaba-damo-academy/lingshu)).
- [LLaVA-Med: Training a Large Language-and-Vision Assistant for Biomedicine in One Day](https://arxiv.org/abs/2306.00890) - Rapidly trained LVLM used as a base for multimodal agents (arXiv, 2023).
- [LLaVA-Rad: Towards a clinically accessible radiology foundation model: open-access and lightweight, with automated evaluation](https://arxiv.org/abs/2403.08002) - 7B chest X-ray report-generation model trainable and servable on a single GPU, released with the CheXprompt automated evaluator; the lightweight option for locally hosted radiology agents (arXiv, 2024; [Code](https://github.com/microsoft/LLaVA-Rad)).
- [M3D: Advancing 3D Medical Image Analysis with Multi-Modal Large Language Models](https://arxiv.org/abs/2404.00578) - 3D medical MLLM covering volumetric VQA, report generation, and referring segmentation; supplies the volumetric perception layer for CT and MRI agents (arXiv, 2024; [Code](https://github.com/BAAI-DCAI/M3D)).
- [MAIRA-2: Grounded Radiology Report Generation](https://arxiv.org/abs/2406.04449) - Grounded chest X-ray reporting model that emits bounding boxes alongside report sentences, providing the spatial evidence that verification agents check (arXiv, 2024).
- [Med-Flamingo: a Multimodal Medical Few-shot Learner](https://arxiv.org/abs/2307.15189) - Few-shot LVLM pretraining that agents wrap for image+text diagnostic reasoning (arXiv, 2023).
- [Med-Gemini: Capabilities of Gemini Models in Medicine](https://arxiv.org/abs/2404.18416) - Multimodal medical model family with self-training and built-in web search; an early demonstration of tool-augmented reasoning at foundation-model scale (arXiv, 2024).
- [Med-PaLM M: Towards Generalist Biomedical AI](https://arxiv.org/abs/2307.14334) - First generalist biomedical model spanning imaging, text, and genomics on the MultiMedBench suite; the reference point for later multimodal medical backbones (arXiv, 2023).
- [MedGemma Technical Report](https://arxiv.org/abs/2507.05201) - Open 4B/27B medical vision-language models built on Gemma 3 with the MedSigLIP encoder; the most commonly self-hosted backbone in recent open medical agent stacks (arXiv, 2025; [Code](https://github.com/google-health/medgemma)).
- [MedImageInsight: An Open-Source Embedding Model for General Domain Medical Imaging](https://arxiv.org/abs/2410.06542) - Cross-modality medical embedding model for classification and image-image search, reporting stronger demographic fairness than prior public encoders; used as the retrieval index behind image-grounded agents (arXiv, 2024).
- [MEDITRON-70B: Scaling Medical Pretraining for Large Language Models](https://arxiv.org/abs/2311.16079) - Strong medical foundation model often paired with external tools in agent workflows (arXiv, 2023).
- [MedVersa: A Generalist Foundation Model for Medical Image Interpretation](https://arxiv.org/abs/2405.07988) - Generalist learner that dispatches to segmentation, detection, and reporting heads from a single interface, making it a natural drop-in perception module for imaging agents (arXiv, 2024).
- [Merlin: A Computed Tomography Vision-Language Foundation Model and Dataset](https://arxiv.org/abs/2406.06512) - 3D abdominal CT vision-language model supervised by EHR diagnosis codes and radiology reports; a volumetric backbone for CT retrieval and triage agents (arXiv, 2024; [Code](https://github.com/StanfordMIMI/Merlin)).
- [PMC-LLaMA: Towards Building Open-source Language Models for Medicine](https://arxiv.org/abs/2304.14454) - PMC-pretrained medical LLM used as a lightweight base for agent orchestration (arXiv, 2023).
- [Prov-GigaPath: A whole-slide foundation model for digital pathology from real-world data](https://www.nature.com/articles/s41586-024-07441-w) - Whole-slide model pairing a tile encoder with a LongNet slide encoder over 1.3B tiles; supplies slide-level context to WSI navigation agents (Nature, 2024; [Code](https://github.com/prov-gigapath/prov-gigapath)).
- [RAD-DINO: Exploring scalable medical image encoders beyond text supervision](https://arxiv.org/abs/2401.10815) - Image-only DINOv2-style chest X-ray encoder that matches text-supervised encoders without paired reports; the vision tower under several radiology report agents (arXiv, 2024).
- [RadFM: Towards Generalist Foundation Model for Radiology by Leveraging Web-scale 2D&3D Medical Data](https://arxiv.org/abs/2308.02463) - Radiology generalist trained on the MedMD 2D and 3D corpus with interleaved image-text inputs; an early multi-image backbone reused by volumetric agents (arXiv, 2023; [Code](https://github.com/chaoyi-wu/RadFM)).
- [SurgicalGPT: End-to-End Language-Vision GPT for Visual Question Answering in Surgery](https://arxiv.org/abs/2304.09974) - Surgical VQA model that can be wrapped by agent controllers (arXiv, 2023).
- [UNI: Towards a general-purpose foundation model for computational pathology](https://www.nature.com/articles/s41591-024-02857-3) - Self-supervised histopathology encoder pretrained on 100M tiles from 100k slides across 20 tissue types; the default tile feature extractor for pathology agents (Nature Medicine, 2024; [Code](https://github.com/mahmoodlab/UNI)).
